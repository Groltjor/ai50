# Ejercicio Tictactoe (tradicionalmente gato)

Este ejercicio busca implementar la lógica necesaria y el uso de Minimax para realizar movimientos optimos.

En este caso el algoritmo debe siempre emmpatar o ganar, nunca perder.

## Nota importante

El código de implementación de PYGAME y la interfaz gráfica esta desarrollado por Harvard. El trabajo del alumno es implementar MiniMax.
