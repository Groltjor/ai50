# 🎬 Degrees of Separation (IMDB Graph)

Este ejercicio consiste en resolver un problema de grafos aplicado a una base de datos del estilo IMDB. El objetivo es determinar cuántos pasos (grados de separación) existen entre dos actores o actrices, basándose en las películas en las que han trabajado en común con otros.

---

## 🔎 Objetivo

Implementar un algoritmo de búsqueda que permita encontrar la **ruta más corta** entre dos nodos (personas), representando colaboraciones en películas como conexiones en un grafo.

---

## 🧠 Algoritmos involucrados

- **Búsqueda en profundidad (Depth-First Search - DFS)**  
  Como enfoque inicial para explorar caminos entre nodos.

- **Búsqueda en anchura (Breadth-First Search - BFS)**  
  Como alternativa óptima para encontrar el camino más corto de forma más eficiente.

📌 El alumno puede elegir modificar la frontera para adaptar la estrategia de búsqueda.

---

## 📌 Nota

El dataset utilizado simula la estructura de relaciones actor-película de IMDB.  
La visualización del grafo no es obligatoria, pero es posible implementar una para mostrar las conexiones.

---

## 🛠️ Tecnologías utilizadas

- Python 3.x
- Estructuras de datos tipo grafo
- Algoritmos de búsqueda
