# 🧠 Parser (Procesamiento de Lenguaje Natural)

Este ejercicio introduce el uso de técnicas básicas de **Procesamiento de Lenguaje Natural (NLP)**, utilizando la librería **NLTK** para analizar y estructurar oraciones en lenguaje humano.

---

## 🎯 Objetivo

Sanitizar entradas de texto y aplicar reglas gramaticales para:

- Identificar la estructura sintáctica de las oraciones.
- Construir **árboles de análisis gramatical** (parse trees).
- Visualizar cómo se organizan las distintas partes de una oración (sujeto, verbo, objeto, etc.).

---

## 🔧 Herramientas utilizadas

- **Python 3.x**
- **NLTK (Natural Language Toolkit)** – para tokenización, parsing y visualización sintáctica.
- Reglas gramaticales personalizadas (CFG - Context Free Grammar)

---

## 📌 Nota

Este ejercicio forma parte del módulo de NLP del curso de Harvard CS50's Introduction to AI with Python.  
El alumno debe construir las reglas gramaticales y aplicar correctamente el parser sobre oraciones de entrada.

---
