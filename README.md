## Tecnologias y enfoques aplicados en el AI50

A lo largo de este curso la teoría y práctica impartida esta relacionado a algoritmos clásicos y uso de librerías para ML fueron:

- **Búsqueda con inteligencia artificial**
  - Algoritmos de búsqueda no informada: Depth-First Search (DFS), Breadth-First Search (BFS)
  - Búsqueda informada: A* y heurísticas
  - Modelado de problemas como grafos

- **Lógica proposicional**
  - Inferencia con satisfacibilidad (SAT solvers)
  - Conjuntos de conocimiento y modelos
  - Resolución lógica y deducción de hechos

- **Inferencia probabilística**
  - Redes bayesianas
  - Herencia genética y probabilidad condicional
  - Aplicaciones de inferencia probabilística en dominios inciertos

- **Planeación**
  - Representación de estados y acciones
  - Planificación basada en búsqueda
  - Algoritmos como GraphPlan

- **Aprendizaje automático**
  - Clasificación con perceptrones y aprendizaje supervisado
  - Introducción a redes neuronales
  - Uso de TensorFlow para construir modelos de clasificación

- **Procesamiento de lenguaje natural (NLP)**
  - Tokenización, extracción de frases nominales
  - Modelos de lenguaje para completar oraciones
  - Uso de transformers y atención (BERT)

- **Juegos con agentes**
  - Algoritmos Minimax y poda alpha-beta
  - Aplicación en juegos como Tic-Tac-Toe
  - Agentes inteligentes para toma de decisiones adversariales
